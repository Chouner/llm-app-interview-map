# 大模型应用开发面试知识地图

把 AI 应用开发岗位的面试知识，按“先学什么、后学什么”串成主线：127 个知识点、183 条先修关系，每个知识点都写清楚它在链路中的位置、和其他模块的关系，以及要掌握到什么深度。

**在线浏览：** https://chouner.github.io/llm-app-interview-map/

## 和普通面试题库有什么不同

- **按链路组织，不是按题目罗列。** 每个知识点都能看到完整的学习链路，比如：评测与优化 → 评测指标 → 金标准评测集 → 抽样策略，每一步都写了为什么需要前一步。
- **跨模块的关系写清楚。** 比如“评测与优化”在业务落地里怎么用（影子模式对比 AI 和人工）、在微调里怎么用（证明微调有效）。
- **三级技术深度。** 每个知识点分入门、熟练、深入三级，对照面试要求判断自己在哪一级。
- **来自真实需求。** 知识点范围来自 43 条 AI 应用开发岗位 JD 和真实面试中的追问，46 个知识点在真实面试中被问到。

## 文件

```
index.html            知识地图浏览页（单文件，无构建步骤）
data/graph.json       知识点、分组、先修关系和说明
scripts/validate.py   校验脚本：字段齐全、先修存在、无环
docs/schema.md        数据格式说明
```

## 本地查看

页面通过 `fetch` 读取数据，不能直接双击打开，需要启动一个静态服务器：

```bash
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/
```

## 校验

```bash
python3 scripts/validate.py
```

全部通过时输出 `VALIDATION PASSED`。修改 `data/graph.json` 后请先运行校验再提交。

## 内容来源

- 岗位要求：南京地区 43 条 AI 应用开发岗位 JD
- 面试追问：真实面试记录，已去除公司信息
- 覆盖参考：公开的大模型应用课程大纲，仅用于检查有没有遗漏的知识点

知识点的说明、链路关系、技术深度和面试要点均为本项目原创整理，未照搬任何课程或题库内容。

## 状态

第一版（v0.1.0）。先修关系和深度划分是作者根据岗位要求和面试经验做的判断，难免有不准确的地方，欢迎通过 Issue 指出。

## 追问练习

知识地图之外，“追问”网站提供真实面试的追问链练习：逐层展开面试官的追问，对照关键点检查自己讲到了哪些，没讲到的自动进入复习清单。网站即将上线，地址会更新在这里。
